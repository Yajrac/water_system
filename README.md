# Pio Duran Water Supply ? Admin Website

A plain HTML, CSS, and JavaScript admin website for managing water supply customer records, billing, and payments.

## Features

- Customer registration, profiles, document checks, and account activation.
- Monthly meter readings, bill generation, and configurable rates and fees.
- Full or partial payments, payment history, and printable receipts.
- Dashboard charts, account reports, and consumption by barangay.
- Notification drafts, search filters, light/dark mode, and a collapsible sidebar.
- Responsive layouts and skeleton loading for fetched sample data.


## Run locally

Open the project using your editor's local web server or Live Server, then open the root `index.html`. No installation or build step is required. A local server is needed for JSON fetching.

Preview login: **admin** / **Admin123!**

## Current scope

This is a local prototype. Records are stored in the browser's localStorage, and login uses a frontend session check. A backend, database, and server authentication are required before real deployment. Notifications are saved as drafts only. Forgot Password, Settings record downloads, and Report CSV export are placeholders.
